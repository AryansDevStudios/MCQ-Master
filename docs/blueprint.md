# **App Name**: QuizCraft AI

## Core Features:

- AI Quiz Generation: Generates quizzes from a given topic, difficulty and style, optionally using provided context as a tool to increase quality and relevance.
- JSON Quiz Import: Allows users to import quizzes from JSON files or editor.
- Quiz Taking: Presents questions with multiple-choice options and supports LaTeX formatting in questions and answers.
- Instant Feedback: Provides immediate feedback on answers with explanations and option to shuffle answers for further study.
- Quiz History: Keeps track of completed quizzes with scores and time spent for review.
- Quiz Saving: Allows users to save generated or imported quizzes for later use.
- Detailed Review: After completing a quiz, users can review their answers, correct solutions, and explanations for each question.

## Style Guidelines:

- Primary color: HSL(260, 59%, 61%) which converts to hex code #A357E8, offering a vibrant purple for primary actions.
- Background color: HSL(260, 23%, 24%) which converts to hex code #3D315B, providing a dark, desaturated purple backdrop.
- Accent color: HSL(230, 58%, 54%) which converts to hex code #5777E8, complementing the primary color with a cooler tone.
- Headline font: 'Space Grotesk', a sans-serif font for headlines and shorter content. Body text font: 'Inter' sans-serif for readability in longer text passages.
- Lucide-react icons are used throughout the application for a consistent and modern look.
- Glassmorphism effects used for cards and UI elements to give a modern, frosted glass appearance.
- Subtle animations on button hover and page transitions to improve user experience.
